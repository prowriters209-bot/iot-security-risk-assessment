About the Assessment Tool

Understanding the purpose and assessment methodology.

Project Overview

The IoT Security Risk Assessment Tool is a Python-based prototype designed to evaluate selected security configurations of Internet of Things devices.

It examines configuration areas including network exposure, authentication, encryption, firmware updates, access control, data protection, exposed services and security logging.

Assessment Methodology

The application uses a transparent weighted rule-based model. Each security factor receives a risk value and a weighting. The weighted values are combined to produce a score between 0 and 100.

  • 0–24.99: Low risk
  • 25–49.99: Medium risk
  • 50–74.99: High risk
  • 75–100: Critical risk
Important Limitations

The prototype evaluates information entered by the user. It does not perform penetration testing, network scanning, firmware analysis or automatic vulnerability verification.

Its scores are indicative outputs from the prototype's predefined rules, not certified security ratings.
